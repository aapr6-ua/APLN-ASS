# Practice APLN - BOE Automatic Summarization System

This project focuses on designing an automatic summarization system for extracting information from documents about scholarships published in the BOE (Boletín Oficial del Estado). These original documents are very long and have a lot of information that is not relevant for the student, so a system that obtains the information a student needs in mere seconds is of great utility.

The objective is to design the system with two main parts: extraction and generation. With the first part we get from the original documents the information we consider most important, while in the generation part of the system we create the final summary written in a natural and comprehensive way.
